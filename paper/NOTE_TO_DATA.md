# Every number in the Research Note, and where to check it

This maps each claim in *A Label-Free Reliability Test for FR-I/FR-II Classification in
Blind Radio Surveys* to the file that produced it. It is for a reader who arrives from the
note's data-availability line and wants to verify a specific figure.

`scripts/verify_note_numbers.py` checks the 17 headline numbers automatically against the
JSON outputs and fails if any has drifted. Run it before any resubmission.

## What the note does not report, and where to find it

The repository contains results the note had no room for, all in `research/RESULTS.md`:

- Three **withdrawn** results from the first version of this work (T1's pass, the mis-paired
  n = 833 T2, and the tautological bridge-flip claim), retained with the reason rather than
  deleted.
- The **leakage sensitivity** test (30″ versus 2.25′ gate), which moved every diagnostic by
  under 0.25 pp.
- The **normalisation sensitivity** test, which passes but only because the confound it
  looks for turns out to be rare — a distinction the note has no space to draw.
- The **device-consistency** measurement after moving all inference to GPU: one flip flag
  changed out of 7348 sources.
